# Okładki Infopacków

Te pliki są miniaturami okładek oryginalnych Infopacków Samorządu Studentów UEW. Nie są ilustracjami wygenerowanymi na potrzeby strony. Dzięki temu żywe przewodniki zachowują wizualny związek z dokumentami źródłowymi, a student od razu rozpoznaje materiał.

## Mapa źródeł

| Plik | Dokument źródłowy |
| --- | --- |
| `regulamin-cover.jpg` | Regulamin studiów w pigułce |
| `podania-cover.jpg` | Składanie podań |
| `usos-cover.jpg` | Poruszanie się po USOS |
| `semestr-cover.jpg` | Zasady zaliczenia semestru |
| `sprawy-cover.jpg` | Sprawy studenckie i dziekańskie |
| `biblioteka-cover.jpg` | Korzystanie z biblioteki |
| `zycie-cover.jpg` | Życie studenckie |
| `dyplomowanie-cover.jpg` | Dyplomowanie |

Dokładne adresy dokumentów są utrzymywane w `src/lib/living-documents.ts` i pozostają nadrzędnym źródłem prawdy.

## Zasady aktualizacji

1. Po zmianie dokumentu źródłowego pobierz aktualną okładkę z tego samego pliku Google Drive.
2. Zachowaj istniejącą nazwę pliku i format JPG, żeby nie zmieniać komponentów.
3. Sprawdź kadr na szerokości telefonu i desktopu. Pliki źródłowe są pionowe, a komponent obraca je do poziomego formatu okładki.
4. Nie zastępuj okładek obrazami stockowymi ani generowanymi przez AI. Zdjęcia reportażowe mogą uzupełniać przewodnik, ale nie powinny udawać dokumentu źródłowego.
